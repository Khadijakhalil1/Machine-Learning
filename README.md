## 🚀 Projects

### 📧 SMS Spam Classifier
> A Machine Learning web app that detects whether a message is Spam or Not Spam.

**Technologies Used:**
- Python
- NLTK (Natural Language Processing)
- Scikit-learn (Multinomial Naive Bayes)
- TF-IDF Vectorizer
- Streamlit (Web Interface)
- Pickle (Model Saving & Loading)

**How it Works:**
1. User enters a message in the web app
2. Text is cleaned and preprocessed using NLTK
3. TF-IDF converts text into numerical features
4. Naive Bayes model predicts Spam or Not Spam
5. Result is displayed instantly on screen

**Key Features:**
- Real-time spam detection
- Clean and simple web interface
- Trained on SMS Spam Collection Dataset
